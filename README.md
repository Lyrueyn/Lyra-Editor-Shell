# 编辑器窗口（Editor Shell）

编辑器扩展的单窗口外壳。

- 左侧固定项目文件树。
- 右侧按文件类型内嵌 HTML 编辑器 / JavaScript 编辑器插件。
- 所有文件切换在同一个窗口内完成，不再额外弹新窗口。
- 需要主程序 2.1.4+、编辑器扩展 1.1.1+。

## 1.1.0

- 新增 6 套界面风格：经典蓝、深空紫、森林绿、暖阳橙、樱花粉、极简白。
- 外壳主题会同步给 HTML / JavaScript 编辑器插件。

## 1.2.0

- 文件树顶层显示项目目录。
- 文件夹右键：新建文件、新建文件夹、重命名、删除。
- 文件右键：重命名、删除。

## 1.2.1

- 文件夹行增加展开/折叠小三角。
- 修复同层级文件夹与文件图标、文件名不对齐的问题。
